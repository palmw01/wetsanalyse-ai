# Bewaarde bronnen

De originelen blijven lokaal in deze map of op hun bestaande locatie. Het gedeelde
[manifest](manifest.json) legt bron-ID, herkomst, versie, status en SHA-256 vast.
Hashes identificeren de bewaarde bytes; zij bewijzen geen juridische geldigheid.

De [skillbronverantwoording](../../../.claude/skills/wetsanalyse/references/bronnen.md)
verbindt instructies met precieze brononderdelen en benoemt eigen projectkeuzes.
Nieuwe exemplaren krijgen een nieuwe versie/raadpleegdatum; overschrijf historische
exemplaren niet. PDF- en HTML-originelen zijn lokaal genegeerd voor Git. Bestaande
bronpublicaties en hun licentievoorwaarden blijven ongewijzigd.

JRM 2 is lokaal bewaard als [PDF](jrm2-2024-11-18.pdf), met een
[doorzoekbare extractie](jrm2-2024-11-18.pages.md). De overheid.nl-download faalde
op DNS; op 2026-09-12 is het document via PNA opgehaald. Titel, auteurs, interne
versie2024-11-18, paginatal en relatieschema zijn gecontroleerd. De PNA-bestandsnaam
noemt2024-11-29; dat is niet de versiedatum op de titelpagina. Beide vindplaatsen
en hashes staan in het manifest. Diagrammen blijven in het origineel leidend.

De drie Staatsbladen zijn historische publicaties voor afgebakende tekstanalyse,
geen geconsolideerde weergave van het huidige recht.
